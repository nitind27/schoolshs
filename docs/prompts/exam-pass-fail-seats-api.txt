Replace:
  BASE   = live site, e.g. https://your-school-domain.com
  TOKEN  = Bearer token from POST /api/auth/mobile/login
  CLASS  = classId
  EXAM   = examId (class Annual exam id)
  TERM   = term key: mid1 | mid2 | final | custom key from terms[]
  STUDENT_TOKEN = student Bearer token

All staff APIs (teacher / clerk / school_admin):
  Header: Authorization: Bearer TOKEN
  Header: Accept: application/json
  Header: Content-Type: application/json   (for PUT / PATCH)

CORS: OPTIONS is enabled on these routes.

Default school rule (until web saves new ones):
  passMarks = 33 (out of 100)
  passPercent = 33
  grades: A1 91+ / A2 81+ / B1 71+ / B2 61+ / C1 51+ / C2 41+ / D 33+ / E 0+
  result: pass | fail | pending
  pending = no marks entered yet
  pass/fail uses school passPercent (same on web + app)

Category filter values:
  SC | ST | OBC | SEBC | EWS | Open | Minority | NTDNT

Web page (same data):
  /results/pass-fail
  /exams  (created-by name on exam chips)

A. TEACHER — Exam Seat Numbers (BUG FIX)
============================================================

Screen: Exam Seat Numbers (homeroom class).

OLD BUG: GET /api/exam-seat-numbers?classId=&examId= returned students: []
because the app did not send termKey. SERVER IS NOW FIXED.

Use:
  GET /api/exam-seat-numbers?classId={classId}&examId={examId}
  Optional: &termKey={mid1|final|...}

Must render:
  student.seatNumber          // primary field — this was empty before
  student.seats[]             // all terms if you show a term picker

If terms[] has more than one exam, show a term dropdown and reload with termKey.
If terms[] is empty, show "Create exam on web first".

Save:
  PATCH /api/exam-seat-numbers
  body: { "classId", "examId", "termKey?", "updates": [{ "studentId", "seatNumber" }] }

Publish:
  PATCH body: { "classId", "examId", "termKey", "action": "publish" }

Also: GET /api/teacher now includes student.seatNumber and student.examSeats.
If the dedicated seat API fails, fall back to those fields. Never show blank
when seatNumber is a non-empty string.
