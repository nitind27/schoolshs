================================================================================
SHS — Absent (AB) marks
CURL + UI RESPONSE
================================================================================

Replace:
  BASE    = http://localhost:3000   or live site
  TOKEN   = Bearer token from POST /api/auth/mobile/login
  CLASS   = classId
  EXAM    = examId
  TERM    = mid1 | mid2 | mid3 | final
  STUDENT = studentId
  SUBJECT = subject code, e.g. MATH  (or the code returned by GET)

Staff only: school_admin, teacher, clerk
Header: Authorization: Bearer TOKEN
Header: Accept: application/json
Header: Content-Type: application/json   (POST only)

Web UI (same APIs, login cookie — no Bearer):
  Marks entry grid : BASE/results/term?classId=CLASS&term=TERM
  Old marks entry  : BASE/results/entry?examId=EXAM
  Marks sheet      : BASE/results/marks-sheet?classId=CLASS
  Gun patrak       : BASE/results/gun-patrak?classId=CLASS&term=TERM
  Result print     : BASE/results/print?examId=EXAM&classId=CLASS

What AB does:
  Checkbox AB under each subject.
  isAbsent true  -> marks cleared, saved as absent, UI shows AB.
  isAbsent false -> teacher can type marks again.
  Stored per exam term in ExamResult.remarks JSON: { "absent": { "mid1": true } }
  Final exam also sets ExamResult.isAbsent = true and marksObtained = 0.
  Absent subject counts as 0 in the total. The cell itself prints AB, not 0.

================================================================================
2) SAVE AB  (UI: tick AB, then Save)
================================================================================

----- CURL -----
curl -sS -X POST -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" ^
  -H "Accept: application/json" ^
  "BASE/api/results/term-marks" ^
  -d "{\"action\":\"save_marks\",\"examId\":\"EXAM\",\"classId\":\"CLASS\",\"term\":\"mid1\",\"students\":[{\"studentId\":\"STUDENT\",\"subjectMarks\":[{\"subjectCode\":\"MATH\",\"termValue\":null,\"internalValue\":null,\"isAbsent\":true},{\"subjectCode\":\"ENG\",\"termValue\":54,\"internalValue\":16,\"isAbsent\":false}]}]}"

----- RESPONSE: 200 -----
{
  "success": true,
  "saved": 2
}

Database:
  ExamResult.remarks for MATH contains "absent": { "mid1": true }
  Paper and internal for that term are null.
  If term is final, ExamResult.isAbsent = true and marksObtained = 0.

UI after reload:
  Toast / green line: "Marks saved successfully!"
  MATH shows AB. ENG keeps the numbers.

================================================================================
FIELD CHEAT SHEET
================================================================================

isAbsent          true / false on each subject in term-marks save and GET
absent            same meaning; accepted if isAbsent is omitted
termValue         paper marks; must be null when isAbsent is true
internalValue     teacher marks; must be null when isAbsent is true
ExamResult.isAbsent   database column; true only for the final exam
remarks.absent    { "mid1": true, "final": true } inside ExamResult.remarks
