################################################################################
# PART A — GALLERY (staff photos / videos)
################################################################################

Hierarchy:
  Event (activityName + date)
    └── Title (album section, e.g. "Prize distribution")
          └── Images / Videos

Allowed:
  Images: JPG, PNG, WEBP, GIF  (compress; keep under ~8 MB input)
  Videos: MP4, WEBM, MOV, M4V  (max 80 MB)
  Max files per upload: 20


--------------------------------------------------------------------------------
A1) LIST gallery events
--------------------------------------------------------------------------------
GET /api/gallery

curl -s "$BASE/api/gallery" \
  -H "Authorization: Bearer $TOKEN"

Response sample:
{
  "canDelete": false,
  "events": [
    {
      "id": "clx_event...",
      "activityName": "Annual Day",
      "eventDate": "2026-01-15",
      "titleCount": 2,
      "imageCount": 12,
      "coverUrl": "/api/uploads/gallery/.../photo.jpg",
      "createdAt": "..."
    }
  ]
}

Cover / media preview:
  GET $BASE{coverUrl}   + Header Authorization: Bearer $TOKEN


--------------------------------------------------------------------------------
A2) CREATE event (activity folder)
--------------------------------------------------------------------------------
POST /api/gallery
Content-Type: application/json

curl -s -X POST "$BASE/api/gallery" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"activityName":"Sports Day","eventDate":"2026-02-10","title":"Opening ceremony"}'

# title optional — pehle se ek title bana sakte ho
# Response 201: { "event": { "id": "...", "titles": [ { "id": "...", "title": "..." } ] } }

EVENT_ID=clx_event...
TITLE_ID=clx_title...   # from response.titles[0].id

--------------------------------------------------------------------------------
A5) UPLOAD images / videos to a title  ★ main Flutter upload
--------------------------------------------------------------------------------
POST /api/gallery/titles/{titleId}/images
multipart/form-data

Field name: files   (multiple OK)  OR  file  (single)

curl -s -X POST "$BASE/api/gallery/titles/$TITLE_ID/images" \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@/path/to/photo1.jpg;type=image/jpeg" \
  -F "files=@/path/to/photo2.jpg;type=image/jpeg"

# single:
curl -s -X POST "$BASE/api/gallery/titles/$TITLE_ID/images" \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@/path/to/photo.jpg;type=image/jpeg"

# video:
curl -s -X POST "$BASE/api/gallery/titles/$TITLE_ID/images" \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@/path/to/clip.mp4;type=video/mp4"

Response 201:
{
  "images": [
    {
      "id": "...",
      "url": "/api/uploads/gallery/SCHOOL/EVENT/TITLE/xxx.jpg",
      "kind": "image",
      "canDelete": true,
      ...
    }
  ]
}


--------------------------------------------------------------------------------
A6) VIEW / DOWNLOAD media
--------------------------------------------------------------------------------
GET {BASE}{url}   e.g. /api/uploads/gallery/...

curl -s -o out.jpg \
  -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/uploads/gallery/SCHOOL_ID/EVENT_ID/TITLE_ID/file.jpg"

# Single image download (attachment)
curl -s -OJ \
  -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/gallery/images/IMAGE_ID/download"

# Whole title as ZIP
curl -s -OJ \
  -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/gallery/titles/TITLE_ID/download"

--------------------------------------------------------------------------------
B3) Admin create / release (optional — usually web)
--------------------------------------------------------------------------------
# Create
curl -s -X POST "$BASE/api/activities" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action":"create","title":"Sports Day","titleGu":"સ્પોર્ટ્સ ડે","type":"sports","date":"2026-02-10","venue":"Ground"}'

# Add students
curl -s -X POST "$BASE/api/activities" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action":"add_participants","id":"ACTIVITY_ID","studentIds":["stu1","stu2"]}'

# Release to teachers
curl -s -X POST "$BASE/api/activities" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action":"release","id":"ACTIVITY_ID"}'

# Unrelease
curl -s -X POST "$BASE/api/activities" \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action":"unrelease","id":"ACTIVITY_ID"}'


--------------------------------------------------------------------------------
B4) Flutter activities screen flow
--------------------------------------------------------------------------------

1. Login teacher → save token
2. GET /api/activities
3. Cards: title, date, venue, type, participant count (_count.participants)
4. Banner: teacherClasses (e.g. "Class 9-D")
5. Tap → GET /api/activities?id=...
6. List students: roll, GR, name EN/GU, class
7. Print / share from Flutter using same list

Name display:
  locale GU → firstNameGu + surnameGu (fallback English)
  locale EN → firstName + middleName + surname
